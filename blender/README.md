# Animation Graph Editor для Blender

Аддон для поканального редактирования F-Curves активного объекта. Требуется Blender 4.5 или новее.

## Установка и первый запуск

1. В Blender откройте **Edit → Preferences → Get Extensions**, нажмите стрелку меню справа сверху, выберите **Install from Disk** и укажите `animation_graph_editor.zip` из этой папки.
2. Выберите объект, наведите курсор на область, где нужен редактор, и нажмите **F3 → Animation Graph Editor**. В Timeline редактор также открывается иконкой кривой справа от **Playback**.
3. В меню каналов выберите, например, **Location Z**. Дважды щёлкните в двух местах графика и нажмите **Space**, чтобы увидеть движение объекта.
4. Нажмите **Esc** над графиком или кнопку с иконкой кривой в заголовке, чтобы вернуться к прежнему редактору. Анимация сохраняется в обычном Action внутри файла `.blend`.

## Управление

| Действие | Управление |
|---|---|
| Добавить ключ в указанном кадре и значении | Двойной щелчок ЛКМ |
| Выбрать ключи или ручки | Щелчок или рамка ЛКМ. Shift добавляет к выделению |
| Переместить выбранные ключи | Потяните ключ. Первое движение выбирает ось времени или значения |
| Изменить касательную | Потяните ручку выбранного ключа. Shift фиксирует исходное направление |
| Повернуть или масштабировать ручки одного ключа | R или S, затем движение мыши. ЛКМ подтверждает, Esc отменяет |
| Выставить Bézier, Linear или Constant | 1, 2 или 3. Можно выбрать одну ручку, чтобы изменить только прилегающую сторону |
| Выделить всё, скопировать, вставить к текущему кадру | Ctrl+A, Ctrl+C, Ctrl+V |
| Удалить выбранные ключи | X или Delete |
| Сместить или приблизить вид по времени | Перетаскивание СКМ или колесо мыши |
| Показать выделение или весь канал | F над графиком |
| Перейти на кадр | Потяните верхнюю или нижнюю шкалу времени |
| Воспроизведение, возврат к началу диапазона | Space, Shift+Space |
| Развернуть область | Ctrl+Space в стандартной раскладке Blender |
| Отменить или повторить правку | Ctrl+Z или Ctrl+Shift+Z |

Меню показывает каналы активного слота Action, включая уже анимированные свойства и кости. Каналы трансформации объекта можно создать с первого ключа. Значения соответствуют данным F-Curve, в том числе радианам для углов Эйлера. По горизонтали ключи сохраняют порядок и останавливаются перед соседями. Для редактирования в NLA выйдите из Tweak Mode.

## Сборка из исходников

Команда для сборки из корня репозитория

```sh
blender --command extension build --source-dir blender/animation_graph_editor --output-filepath blender/animation_graph_editor.zip
```
